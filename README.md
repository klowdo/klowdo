## ⌨️ kixvim — my NixVim config

[**kixvim**](https://github.com/klowdo/kixvim) is my Neovim, configured entirely in Nix.
I broke it out of my system config so I can hack on plugins without rebuilding NixOS.

```sh
nix run github:klowdo/kixvim
```

LSP + Treesitter, Telescope, Neotest, Harpoon, Flash, LazyGit and Claude Code integration — leader is `Space`.
